# S Square Elite Gift Shop — React + Vite

A mobile-first gift and toy shop frontend built with React, Vite, React Router and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Included

- Product-forward homepage with multiple product collections
- Category browsing pages that continue into subsequent categories as the customer scrolls
- Mobile-first responsive product cards (rectangular product tiles on mobile)
- Search, sorting, product detail pages, favourites/wishlist and shopping bag
- Browser local storage for cart and favourites
- Rotating delivery/promotional announcement bar
- Related product recommendations
- Starter account and checkout screens

## Important notes

This is a frontend starter with sample product data and emoji artwork. Replace the sample products with real product photos and verified prices before publishing. Authentication, inventory, order creation and payment gateway processing are not connected yet; connect these to a secure backend before accepting real orders.
